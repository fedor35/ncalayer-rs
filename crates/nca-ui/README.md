# nca-ui

Граница между демоном `ncalayerd` и пользовательским интерфейсом.

* Трейт `Ui` — всё, что демон просит у фронтенда: выбрать контейнер ключа, спросить пароль,
  показать ошибку, уведомить, переключить язык (`changeLocale`). Методы вызываются из задач tokio;
  фронтенд со своим UI-потоком сам перебрасывает вызов туда.
* `Settings` — `settings.json` в каталоге данных: список недавних контейнеров (до 10, без дублей),
  язык, «запускать свёрнутым». Старое поле `recentPath` оригинального NCALayer подхватывается.
* `i18n` — таблица строк ru/kk/en.
* Запасные реализации: `DialogUi` (kdialog/zenity) и `FixedUi` (headless,
  `NCALAYER_TEST_KEY=<путь>:<пароль>` — для тестов и CI).

Настоящий GUI — в крейте `nca-ui-slint`.
