# gost3410

Чистая Rust-реализация подписи ГОСТ Р 34.10-2012 (RFC 7091) для открытой замены NCALayer.

## Что есть

* Кривые Вейерштрасса `y² = x³ + ax + b` над `F_p`; арифметика на `crypto-bigint` (`U512`, форма Монтгомери), точки в якобиевых координатах, скалярное умножение лестницей Монтгомери.
* Именованные наборы параметров (`NamedCurve`):
  * `id-tc26-gost-3410-12-512-paramSetA` — KZ OID `1.2.398.3.10.1.1.2.2.1` (основной набор НУЦ РК, Стрибог-512);
  * `id-tc26-gost-3410-2012-256-paramSetA` (форма Вейерштрасса из RFC 7836 A.2, кофактор 4) — KZ OID `1.2.398.3.10.1.1.2.1.1` (Стрибог-256);
  * `GostR3410-2001-CryptoPro-A` — KZ OID `1.2.398.3.10.1.1.1.1.1` (ГОСТ 34.310-2004, ГОСТ Р 34.11-94 CryptoPro) — для проверки старых подписей.
  Произвольные параметры — `Curve::from_params(p, a, b, q, x, y)`.
* `sign` (внешний `rand_core::CryptoRng`), `sign_deterministic` (HMAC-DRBG по Стрибогу в духе RFC 6979), `sign_with_k` (для тест-векторов), `verify`.
* Хэши — через крейты RustCrypto `streebog` и `gost94` (`digest_for_curve`, `HashAlg`).

## Порядок байт (главное)

| Что | Формат | Где |
|---|---|---|
| Хэш → число `e` | байты из `streebog`/`gost94` (порядок как у CryptoPro/gost-engine/KalkanCrypt) читаются как **little-endian** число | RFC 4490 §2.2.1, проверено на сертификатах НУЦ |
| Подпись «по ГОСТу» | `r ‖ s`, big-endian | ГОСТ §6.1 шаг 7; `Signature::to_bytes_gost` |
| Подпись X.509/CMS по RFC | `s ‖ r`, big-endian | RFC 4491 §2.2.2, RFC 9215 §2; `Signature::to_bytes_rfc4491` |
| Подпись в сертификатах НУЦ РК | `r ‖ s`, **little-endian** (побайтовый реверс формата RFC) | эмпирически, `tests/nca_certs.rs`; `Signature::to_bytes_kz` |
| Открытый ключ в X.509 | `x ‖ y`, little-endian | RFC 4491 §2.3.2, RFC 9215 §4.3; `PublicKey::to_bytes_x509` (НУЦ ему следует) |

## Тесты

`cargo test -p gost3410` (12 тестов, ~2 с в debug):

* примеры из приложения А ГОСТ Р 34.10-2012 (256 бит — RFC 7091 §7, 512 бит — А.2), включая `sign_with_k` → точные `r, s`;
* самоподпись корневого сертификата НУЦ РК `root_gost_2022.cer` и подпись `nca_gost_2022.cer` корнем (`tests/data/`);
* `G` на кривой и `q·G = O` для всех именованных кривых; round-trip и негативные тесты.

## Ограничения

* Не constant-time: арифметика поля — да, но бит скаляра и особые случаи сложения точек обрабатываются ветвлениями. Для v1 (подпись локально на ПК пользователя) допустимо.
* Все кривые считаются в ширине 512 бит — 256-битные медленнее, чем могли бы.
* Простота `p` и `q` не проверяется в `from_params`.
